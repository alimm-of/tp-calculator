# Веб-калькулятор цен (на основе цен «Транспортных перевозок»)

Автономный инструмент на Python: берёт актуальные цены из базы ТП (выгрузка файлом),
считает стоимость тем же алгоритмом, что документ «Калькуляция», и служит основой для ваших
собственных тарифов и расчёта доставки до последней мили.

## Поток данных

```
База ТП ──[ВыгрузкаЦен_JSON (внешняя обработка)]──> цены.json
                                                       │
                                     [python cli.py import цены.json prices.db]
                                                       ▼
                                                  prices.db (SQLite)
                                                       │
                            [python app.py]  →  веб-калькулятор  (или cli.py calc)
```

Обновление цен — **ручное**: периодически перевыгружаете `цены.json` в базе ТП и повторяете `import`.

## Быстрый старт

```bash
pip install -r requirements.txt          # только Flask (для веб-интерфейса)
python cli.py import sample/prices_sample.json prices.db
python app.py                            # http://127.0.0.1:5000
# либо без веб-сервера:
python cli.py calc prices.db --вес 1000 --объём 2 --вид-товара ВТ1 --упаковка Короб --склад СКЛ1 --клиент К1
```

Проверка расчёта: `python tests/test_engine.py` (5 сценариев).

## Структура

```
tp_calc/
  engine.py       — ядро расчёта (порт тп_РасчетЦен: базовый путь + допрасходы)
  models.py       — PriceRepository: приоритетный подбор цены (источники 0..5) поверх SQLite
  extensions.py   — ВАШИ точки расширения: свои тарифы, last-mile, бренд/Z, «по новому»
  importer.py     — импорт JSON-выгрузки в SQLite
  schema.sql      — схема БД (таблицы = ценовые регистры ТП)
app.py            — Flask веб-калькулятор (single-file UI)
cli.py            — импорт и расчёт из командной строки
sample/prices_sample.json — пример выгрузки (структура = реальная выгрузка ТП)
ВыгрузкаЦен_JSON_МодульФормы.bsl — внешняя обработка для базы ТП (выгрузка в этот JSON)
```

## Что перенесено достоверно, а что — точки расширения

Перенесён **базовый путь «по старому»** (совпадает с документом «Калькуляция»):
приоритетный подбор базовой цены по 6 источникам (клиент+вид/группа/склад → без склада → по виду
товара), выбор цены за тонну/куб, экспресс-цена, допрасходы за доставку по коэффициенту дорожных
расходов или по таблице.

**Точки расширения (`extensions.py`)** — пока заглушки (0), сюда вы добавляете свою логику:
- расчёт «по новому»: перевозка (`тп_ТарифыНаПеревозку`) + растаможка (`тп_ЦеныНаРастаможку`) + наценки (`тп_НаценкиНаТовар`);
- наценки за бренд / Z-товар;
- **свои тарифы и доставка до последней мили (last-mile)** — функции `тариф_перевозки`, `стоимость_последней_мили`.

Данные для этих веток уже выгружаются в JSON и лежат в БД (`tarify_perevozka`, `ceny_rastamozhka`,
`nacenki_tovar`, `stavki_press`) — нужно только реализовать формулы.

## Соглашение об идентификаторах

Ссылочные поля (клиент, вид товара, склад, упаковка) выгружаются из ТП как **Код** справочника
(для перечислений — имя значения). Тот же идентификатор вводится в калькуляторе. Если Код неудобен —
поменяйте `ЗначениеДляJSON` в BSL на `УникальныйИдентификатор` и используйте его везде.
